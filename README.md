#webprint

this program for access printer that doesnt have wireles connectivity like blutooth or wifi, printer that supported can be connected to miniserver using usb, installing this app makes you that already connected using the same wifi network by accessing 

http://192.168.x.x:3000

can send pdf file to print. 

this app cannot print docx file, we recommend print pdf files. uploaded file will be deleted after 10 minutes

#installation

curl -fsSL https://raw.githubusercontent.com/angka/sapi/refs/heads/master/webprint.sh | sudo bash
